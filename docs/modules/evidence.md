# EvidenceStore：单次运行的证据回查

意图：把模型已经观察到的工具结果保存为可回读证据，压缩上下文后仍能查证命令结果。它是本次运行的文件仓库，不是长期记忆、进程恢复或评分数据入口。Agent 负责决定哪些观察入库、何时呈现摘要，并把 Trace.clean 注入为脱敏函数；此模块不调用模型或执行代码。

## 方法约定

- `EvidenceStore(directory, *, redactor, max_item_bytes=1_048_576, max_total_bytes=33_554_432)`：建立专属目录与内存登记表。目录由可信控制层提供；模型从不获得宿主路径。额度必须为正整数。新实例不加载旧文件，因此不能跨运行猜 ID 读取证据；调用方必须为每次运行提供独立目录，额度统计只覆盖本实例成功写入内容。
- `store(text) -> dict`：先完整脱敏，再编码 UTF-8、计算哈希并独占创建文件。返回 `id/sha256/chars/bytes/truncated`，哈希和长度对应实际存储的脱敏文本。随机 ID 形如 `ev_` 加 32 个小写十六进制字符。单项超过字节额度时只保留 UTF-8 完整字符前缀，truncated=true；总额度不足则抛 EvidenceError，不产生文件、不登记 ID、不消耗额度。文件创建/写入失败同样不登记；不会重写已有同名证据。
- `contains(id) -> bool`：只接受当前实例已登记的 ID，用于 checkpoint 引用校验；这不是文件完整性验证。
- `read(id, start=0, limit=4000) -> dict`：按 Unicode 字符偏移分页，单次 1–16000 字符。只读取登记记录对应的文件并验证字节数与 SHA-256；拒绝 symlink、丢失或被篡改的文件。成功返回 `ok/id/content/start/next_start/total_chars/truncated`。next_start 是下一页起点，无后续内容时为 null；truncated 表示当前页还有内容未读完，或入库时已永久截断。start 可以等于总长度并返回空页，不能超过总长度。

读失败返回 ok=false 和固定错误，未知 ID、非法范围、I/O、完整性失败均不回显输入或宿主路径。写失败抛安全可显示的 EvidenceError，底层异常不应直接作为模型观察。工具层还有独立严格参数校验。返回 metadata 是副本，调用方修改不会影响登记。

## 边界与验证

证据文件不可通过本 API 覆写；存储哈希用于检测文件被外部修改，不承担恶意宿主的权限隔离。目录不能暴露给沙箱，也不能放入待导出的项目补丁。总磁盘保留与运行结束后清理由控制层负责，本组件不自动删除历史运行。

保存的是上游实际传入的有界工具结果；worker 在交给 Agent 前已截断的原始 stdout/stderr 无法由此还原，不能把本模块描述成完整进程日志。单项永久截断明确暴露，模型不应假定被截去内容还能回查。

回归覆盖见 tests/test_evidence.py 与 docs/testing-evidence.md；代码不触发模型、容器或网络请求。
